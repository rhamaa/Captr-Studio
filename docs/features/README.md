# Katalog fitur

Katalog ini menjelaskan fungsi, workflow, dan batas setiap subsistem. Gunakan [status fitur](../product/status.md) untuk membedakan implementasi current dengan backlog.

| Fitur | Halaman | Pemilik utama |
| --- | --- | --- |
| Capture layar/jendela dan multi-stream | [Recording](recording.md) | Capture service dan Assets project |
| Efek rekaman, cursor, webcam, zoom | [Record Editor](record-editor.md) | Komposisi Record per placement |
| Editing video final | [Story Editor](story-editor.md) | Story/Artboard aktif |
| Multi-output dan infinite canvas | [Artboard dan Whiteboard](artboards-whiteboard.md) | Project dan Artboard |
| Library media dan preset desain | [Assets dan Templates](assets-templates.md) | Global, privat Story, dan preset |
| Narasi dan audio timeline | [Voiceover dan Audio](voiceover-audio.md) | Source privat serta placement |
| Speech-to-text dan subtitle | [Transkripsi dan Caption](captions-transcription.md) | Source transcript serta metadata Story |
| Agent dan rencana editing | [AI Copilot](ai-copilot.md) | Context scope yang tertangkap |
| Motion graphic berbasis kode | [Hyperframe](hyperframe.md) | Komposisi Hyperframe |
| Rendering dan output | [Export](export.md) | Pipeline sesuai jenis output |
| Home, save, rename, conversion | [Lifecycle Project](project-lifecycle.md) | Identitas project dan transaksi file |
| Ekstensi renderer | [Extensions](extensions.md) | Host API dengan permissions |
