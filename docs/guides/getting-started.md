# Mulai memakai Captr Studio

Workflow dasar adalah membuat project, menyiapkan media, membuka Story/Artboard, mengedit, lalu menyimpan atau mengekspor.

## 1. Buka atau buat project

Mulai dari Home. Gunakan New untuk project baru atau Open untuk `.captr` yang sudah ada. New dan Save As mempunyai identitas baru; Rename hanya mengubah nama file project yang sama.

## 2. Siapkan source

Import video/gambar/audio ke Assets atau jalankan Screen Record. Source dapat disimpan meskipun belum ada clip pada timeline. Hasil Screen Record masuk library global; tempatkan secara eksplisit ketika hendak dipakai.

## 3. Buat output Artboard

Pilih ukuran/aspect ratio output yang tersedia. Buka kartu Story melalui aksi edit pada Artboard untuk masuk Story Editor. Artboard lain dapat memakai source global yang sama dengan urutan dan komposisi berbeda.

## 4. Susun video

Place/drop media ke track yang sesuai. Gunakan split/trim/rate untuk durasi, Text/Shapes untuk desain lokal, Inspector untuk properti, dan Record Editor untuk efek recording pada placement yang dipilih.

Rekam narasi melalui Audio Recorder dari Story. Take menjadi private Story Media dan ditempatkan pada playhead yang ditangkap saat mulai.

## 5. Simpan dan periksa output

Save menyimpan seluruh library dan metadata dalam satu `.captr`, termasuk media tanpa placement. Periksa preview, lalu gunakan export sesuai Story atau Hyperframe. Subtitle preview Story belum menjadi burn-in export final.

Untuk fitur yang belum lengkap, baca [status](../product/status.md). Untuk source development, baca [setup](../development/setup.md).
