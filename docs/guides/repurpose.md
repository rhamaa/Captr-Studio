# Membuat beberapa output dari satu project

Artboard memungkinkan beberapa output dengan nama dan canvas berbeda memakai sumber yang sama. Setiap Story tetap dapat mempunyai sequence sendiri.

## Workflow

1. Import/Record source ke Assets global.
2. Buat Artboard sesuai target, misalnya landscape dan portrait.
3. Place source yang diperlukan pada masing-masing Story.
4. Sesuaikan timing, canvas, framing, serta komposisi Record per placement.
5. Tambahkan desain lokal dan narasi privat di Story terkait.
6. Periksa preview setiap kartu/Story dan pilih workflow export yang sesuai.

Duplikasi Artboard membuat instance desain, private media, placement, dan Record composition independen. Source global tetap dibagi; ini mengurangi duplikasi fisik rekaman sambil menjaga edit lokal.

## Whiteboard versus video output

Sticky note, connector, dan sketch membantu perencanaan pada infinite canvas. Mereka tidak otomatis menjadi elemen video. Untuk judul atau callout pada output, tambahkan Text/Shapes di Story Editor.

Hyperframe dapat menjadi kartu komposisi kode atau menghasilkan media B-roll yang kemudian ditempatkan di Story. Bedakan keduanya ketika merencanakan pipeline.

## Rasio dan preview

Preview zoom/pan mengubah area kerja. Canvas Artboard/Story menentukan resolusi/aspect ratio output. Grid/safe-zone guide membantu framing, tetapi bukan jaminan layout UI setiap platform sosial tidak berubah.
